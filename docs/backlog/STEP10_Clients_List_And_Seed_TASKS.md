# Step 10 — Клиенты: список организаций и демо-данные

Задачи для копирования в новый чат.

---

## Цель

Раздел «Клиенты» в верхней части левого сайдбара — при клике показывать полный список всех организаций (наших клиентов). Добавить seed-данные с 7–8 демо-организациями, чтобы при первом запуске список не был пустым.

---

## Задачи

### [STEP10-1] Seed клиентов (демо-организации)

- Добавить в `app/seed.py` функцию `seed_clients()` и список `CLIENT_SEEDS` с 7–8 организациями
- Примеры: ТОО Альфа, ИП Бета, АО Гамма, ТОО Демо ACME, Impl 3 Demo LLC и т.п.
- Поля: `code`, `name`, `status` (например `active`), `bin` (опционально)
- Вызывать `seed_clients()` в `seed_all()`
- Детерминированные ID через `uuid5(NAMESPACE_URL, f"seed:client:{code}")`

### [STEP10-2] Страница «Клиенты» — полный список организаций

- Маршрут `/clients` — при клике на «Клиенты» в сайдбаре открывается эта страница
- Загрузка всех организаций через `GET /api/clients`
- Отображение карточек: название, код, статус
- Клик по карточке → переход в рабочее пространство `/client/{client_id}`

### [STEP10-3] Проверка и доработка UX

- Убедиться, что при первом запуске (после `seed_all`) в списке отображаются 7–8 организаций
- Пустое состояние: если клиентов нет — подсказка «Создать через мастер onboarding»
- Ссылка на `/wizard` для создания новой организации

Должности: типовая роль и несколько ставок в отделении

Краткое руководство для HR. Светлый фон — для печати или вставки в Word (PDF / скриншот блока диаграммы).

1. Два уровня

УровеньГдеСколько «Ординатор»
Типовая должностьГлобальный справочникОдна запись
Штатная ставкаЛокальные должности организацииПо числу людей в отделении

2. Схема

%%{init: {'theme': 'neutral', 'themeVariables': {'fontFamily': 'Segoe UI, Arial, sans-serif'}}}%%
flowchart LR
  CAT["Типовой каталог: Ординатор"]
  P1["Локальная ставка 1, код ORD_1"]
  P2["Локальная ставка 2, код ORD_2"]
  P3["Локальная ставка 3, код ORD_3"]
  E1["Сотрудник Иванов"]
  E2["Сотрудник Петров"]
  E3["Сотрудник Сидоров"]
  CAT --> P1
  CAT --> P2
  CAT --> P3
  P1 --> E1
  P2 --> E2
  P3 --> E3

3. Текстовая схема (без диаграммы)

  [ Типовой каталог: Ординатор ]
           |
     +-----+-----+-----+
     |     |     |     |
  [ORD_1][ORD_2][ORD_3]
     |     |     |
  Иванов Петров Сидоров

4. Действия в системе

  1. В каталоге — одна должность «Ординатор».
  2. В организации — несколько локальных строк; коды разные, тип каталога один.
  3. На каждую строку: Назначить сотрудника.

# Разрешение Python в брандмауэре Windows

Если `http://localhost:8080/` не открывается в браузере, добавьте Python в исключения брандмауэра.

---

## Шаг 1: Открыть настройки приложений в брандмауэре

1. Нажмите **Win + I** (Параметры Windows)
2. Перейдите: **Конфиденциальность и безопасность** → **Безопасность Windows** → **Брандмауэр и защита сети**
3. Нажмите ссылку **«Разрешить работу с приложением через брандмауэр»**

---

## Шаг 2: Разрешить изменения

1. Нажмите кнопку **«Изменить параметры»** (справа вверху)
2. Если появится запрос UAC — нажмите **«Да»**

---

## Шаг 3: Добавить Python

### Вариант А: Python уже есть в списке

- Найдите в списке **«Python»** или **«python»**
- Поставьте галочки в колонках **«Частная»** и **«Общедоступная»**
- Перейдите к шагу 4

### Вариант Б: Python нет в списке

1. Нажмите **«Разрешить другое приложение»**
2. Нажмите **«Обзор»**
3. Вставьте в адресную строку проводника один из путей:

   **Виртуальное окружение проекта** (предпочтительно):
   ```
   D:\MyActivity\MyInfoBusiness\MyPythonApps\10 Typical_infrastructure\.venv\Scripts
   ```

   **Системный Python**:
   ```
   C:\Users\Sergei\AppData\Local\Programs\Python\Python312
   ```

4. Выберите файл **`python.exe`**
5. Нажмите **«Открыть»**
6. Нажмите **«Добавить»**
7. В списке найдите добавленный **Python** и поставьте галочки **«Частная»** и **«Общедоступная»**

---

## Шаг 4: Сохранить

1. Нажмите **«ОК»** в окне «Разрешенные приложения»
2. Закройте окно параметров

---

## Шаг 5: Запустить сервер и проверить

1. **Остановите** старый процесс сервера, если он запущен (Ctrl+C в терминале)
2. Запустите сервер:
   ```powershell
   cd "D:\MyActivity\MyInfoBusiness\MyPythonApps\10 Typical_infrastructure"
   .\run_http_8080.ps1
   ```
3. Дождитесь сообщения: `Uvicorn running on http://127.0.0.1:8080`
4. Откройте в браузере: **http://localhost:8080/** или **http://127.0.0.1:8080/**

---

## Важно

- **Сервер должен быть запущен** — в терминале должно быть `Uvicorn running on...`. Если видите только приглашение `PS D:\...>`, сервер не работает.
- **Порт 8080** — скрипт `run_http_8080.ps1` использует порт 8080. В адресе должен быть `:8080`.
- **Kaspersky** — если иконка с восклицательным знаком, защита может блокировать соединения. Временно отключите «Сетевой экран» или «Контроль программ» в настройках Kaspersky для проверки.

Сегменты используются для группировки подразделений и должностей по логическим блокам. Обычно они назначаются автоматически при создании организации. Кнопка «Обновить сегменты из шаблона» нужна, если типовой шаблон был обновлён и требуется дозаполнить отсутствующие сегменты.

Локальные KPI

KPI организации разворачиваются из типовых KPI как часть локальных регламентов. Здесь — сводная таблица KPI. Для KPI, привязанного к регламенту: Открыть (карточку регламента), В шаблон (отправить KPI в глобальный справочник), Синхронизировать — подтянуть из глобального регламента только новые строки KPI и инструкций (уже существующие не перезаписываются). KPI «без регламента»: Изменить, В шаблон, Удалить.

Локальные навыки

Навыки разворачиваются из типовой матрицы для должностей, которые есть в организации. В строке: Изменить, Дублировать (копия одной строки), В шаблон, Удалить. Кнопка «Загрузить из шаблона» выше таблицы — массовое копирование матрицы из глобального справочника (это не «Синхронизировать» в строке; в навыках синхронизации построчно нет).

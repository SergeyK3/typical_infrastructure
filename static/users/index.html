Платформенные аккаунты

Платформенные аккаунты используются для администрирования платформы. Они предназначены для назначения Global Admin, передачи полномочий преемнику, делегирования административного доступа и аварийного восстановления доступа.

Раздел находится в разработке. Управление платформенными аккаунтами станет доступно после реализации Platform Account Lifecycle.
